## 3. リッジ回帰 (Leave-One-Subset-Out)

特徴量: `log_people` + DeepGaitV2系5指標(MSD, 1NN, kNN, FID, FID_train_test)。Inception/DINO/生画素は不使用。StandardScaler→Ridge(alpha=1.0)、13サブセットを1つずつテストに回すLODO。

### 精度 (4つの目的変数それぞれで独立に学習)

MAE: 予測精度と実際の精度の差(絶対値)の平均。小さいほど良い。
RMSE: 同様の誤差だが大きな外れ値をより強く罰する指標。小さいほど良い。
Spearman ρ: 「予測した精度の順位」と「実際の精度の順位」がどれだけ一致するか。1に近いほど、データ特性指標だけでどのサブセットが良い/悪いかを正しく順位付けできていることを意味する。

| acc_cl | 0.2289 | 0.4092 | 0.4725 |

## 4. ロジスティック回帰 (3クラス優劣判定, target=acc_all)

論文4.5節に準拠: サブセットペア (A, B) を **A_better / B_better / Tie**(τ=0.05以内の差はTie)の3クラスに分類。特徴はペアの指標差 (feat_A − feat_B)。評価は Leave-One-Subset-Pair-Out(テスト対象ペアとその逆順のみ学習から除外)。13サブセット×順列で **156ペア**。

ペア数: 13サブセットから作れる順列ペア(A,B)と(B,A)を区別して数えた総数(13×12=156)。feat_A−feat_Bという差を特徴に使うため、(A,B)と(B,A)は別サンプルになる。
Accuracy: 156ペアのうち、A_better/B_better/Tieの3クラス分類が正解だった割合(Leave-One-Subset-Pair-Outで評価)。
Macro-F1: 各クラス(A_better/B_better/Tie)ごとにF1スコアを計算して単純平均したもの。Tieクラスはサンプル数が少なく(下記ラベル分布参照)、Accuracyだけだと多数派のA_better/B_betterに引っ張られやすいため、全クラスを均等に評価するMacro-F1を重視(論文5節に準拠)。
ラベル分布: 実際の認証精度差にτ=0.05を適用してTie/A_better/B_betterに分類した結果の内訳(Tieは156中36と少数派)。

| 指標 | 値 |
| --- | --- |
| ペア数 | 156 (13サブセット全順列) |
| Accuracy | 0.7179 |
| Macro-F1 | 0.7024 |
| ラベル分布 | Tie=36, A_better=60, B_better=60 |

## 6. 精度が論文(Inception/DINO)に及ばなかった原因の分析(仮説)

セクション5の通り、Ridge Spearman は論文 0.8352 に対し本結果 0.6978、優劣判定 Accuracy も 0.7949→0.7179。この差の要因として以下が考えられる(いずれも要検証の仮説)。

### (1) 検証方法の構造的な違い

- **DeepGaitV2 はサブセットごとに別モデルを学習し、その自前モデルで埋め込みを抽出している**。一方 Inception/DINO は全サブセット共通の事前学習済みモデル。つまり13サブセットの埋め込みは**13個の別々の特徴空間**に属し、本来は共通座標系でないものを横断で比較・回帰していることになる。指標の大小が「データ特性の差」なのか「モデルの差」なのかを分離できない。
- **さらに問題なのは、指標を測る「ものさし」と、精度を予測したい「対象」が、同じDeepGaitV2モデルになっている点(train-on-train)**。
    - MSD・1NN・kNN・FID は、いずれも **そのサブセットの学習データを、まさにそのデータで学習したモデルで埋め込んだもの** から計算している。モデルは学習で使った人物をいわば「暗記」しているので、埋め込み上では学習人物が実際以上に綺麗に分かれてしまう。
    - すると MSD(クラス内のばらつき)や kNN(似た他人との近さ)は、「そのデータがそもそも識別しやすいか(=データの質)」ではなく、「モデルがどれだけ学習データを覚え込んだか(=過学習の度合い)」を映してしまう。
    - 極端に言えば、**どのサブセットのモデルも自分の学習データは綺麗に分けられる**ので、指標がサブセット間で似た値に潰れ、「良いサブセット/悪いサブセット」の差が指標に出にくくなる。これが順位予測(Spearman)を下げている可能性がある。
    - 一方 **論文の Inception/DINO は CASIA-B では一切学習していない外部の固定モデル**(自然画像で事前学習しただけ)。だから「中立なものさしでデータの性質を測る」ことができ、この暗記の混入が起きない。**この差は論文の指標設計の欠陥ではなく、今回 抽出器を自前学習の DeepGaitV2 に置き換えたことで新たに生じたもの**である点に注意。
    - 傍証: `FID_train_test` だけは **モデルが学習で見ていないテスト49人** を使うため、この暗記の影響を受けない。実際この指標だけが全モデルで最重要特徴になっており、「暗記の混入が無い指標だけがよく効いている」と読める。

### (2) DeepGaitV2 特徴そのものの適性

- DeepGaitV2 の埋め込みは「歩容による個人識別」に最適化されており、汎用の視覚特徴(ImageNet/DINO)とは性質が異なる。データセットの多様性・分布を測る指標として素直に効くとは限らない。
- **どんな特徴を捉えているのか(次元ごとの意味、クラスタ構造、t-SNE等での可視化)を一度調べたほうがよい**。特徴の性質が分かれば、指標の効き方の違いも説明できる可能性がある。

### (3) その他の候補

- **高次元 × 少サンプル**: 4096次元(256ch × 16part を flatten)に対し、1サブセットの学習系列は約1640本、被験者ペアFIDでは1人あたり約20本。共分散が激しくランク落ちしており、FID・分散の推定ノイズが大きい。また 256×16 を単純 flatten した空間がユークリッド距離に適しているかも不明(部位×チャンネルの構造を潰している)。
- **特徴の数・多様性の少なさ**: 論文は Inception 5指標 + DINO 5指標 + 生画素MSD の計11特徴を併用。今回は `log_people` + DeepGaitV2 5指標の6特徴のみで、相補的な信号が無く、LODO 13点では表現力が落ちやすい。
- **13モデルの学習条件の揃い**: 各サブセットの DeepGaitV2 が同じ反復数・同条件で収束しているか。学習量が揃っていないと、埋め込み品質(=指標)が「データ特性」ではなく「学習量」に引きずられる。

次にやるとよいこと: ① 埋め込みの可視化で train-on-train の過学習が起きていないか確認 (train と test の分離度合い)、② 共通の事前学習 DeepGaitV2(全サブセット同一モデル)でも抽出して、per-subset 版と比較 → (1) の寄与を切り分け。

## 7. 特徴抽出器を「共通の事前学習DeepGaitV2(SUSTech1K版)」に置き換えた結果

セクション6で立てた仮説「train-on-train(サブセットごとに別モデルで、しかもそのモデルが学習したデータ自身を測っている)が精度低下の主因」を検証するため、**特徴抽出器だけ**を、CASIA-Bを一切学習していない共通のSUSTech1K版DeepGaitV2チェックポイント(opengait/OpenGait on HuggingFace)に置き換えて再実行した。

**変更点**: 特徴抽出器のみ(per-subset自前学習 → 共通のSUSTech1K版1個)。認識器(acc_nm/acc_bg/acc_cl/acc_allのtarget)は変更なし(サブセットごと学習のまま)。バックボーン構造(p3d, channels:[64,128,256,512])は完全一致、`class_num`(250 vs 75)のみ違うが、抽出する埋め込みはBNNecks手前の`embed_1`でありclass_numに依存しないため影響なし。13サブセットで共通モデル・共通テスト49人を使うため、test側の埋め込みは13サブセットすべてで完全に一致(bit-identical)することを確認済み。

### Ridge回帰(LODO)の比較

|  | MAE | RMSE | Spearman ρ |
| --- | --- | --- | --- |
| 論文 (Inception/DINO) | 0.1146 | 0.2436 | 0.8352 |
| DeepGaitV2 per-subset学習 (旧・train-on-train) | 0.1453 | 0.2376 | 0.6978 |
| DeepGaitV2 共通SUSTech1K版 (新) | 0.0645 | 0.0881 | 0.8022 |

### ロジスティック回帰(3クラス優劣判定, τ=0.05, 156ペア)の比較

|  | Accuracy | Macro-F1 |
| --- | --- | --- |
| 論文 (Inception/DINO) | 0.7949 | 0.7296 |
| DeepGaitV2 per-subset学習 (旧・train-on-train) | 0.7179 | 0.7024 |
| DeepGaitV2 共通SUSTech1K版 (新) | 0.8718 | 0.8622 |

### 結果の解釈

- **train-on-train を解消しただけで、Ridge Spearmanは0.6978→0.8022、優劣判定Accuracy/Macro-F1は0.72/0.70→0.87/0.86に大幅改善**。優劣判定は論文(Inception/DINO)を上回った。
- MAE/RMSEも大きく改善(MAE 0.1453→0.0645、RMSE 0.2376→0.0881)。特徴を測るドメイン(SUSTech1K)がCASIA-Bと違う(ドメインギャップがある)にもかかわらず、これだけ改善したことから、**セクション6の仮説(1): 「サブセットごとに別モデル・自分の学習データを暗記したモデルで測っていたこと」が精度低下の主因だった可能性が高い**ことが実証された。
- 各targetでも一貫して `FID_train_test_DeepGaitV2` が最重要係数のまま(importance=1.785、per-subset版の傾向を維持)であり、「train-test分布距離が精度を最もよく説明する」という論文の定性的結論とも整合する。
- 一方でMSD/kNN等の生の値のレンジは、per-subset版(MSD: 4〜43)より狭く(共通版: MSD 24〜44)なっており、指標としての感度(サブセット間の差の出方)がper-subset版と質的に異なる点には留意。
