## OpenGait を `/home/kera/` にセットアップ

中村さんの `/home/ryu/OpenGait/` を直接触らないよう、自分用にコピーした。

- コード・configs・train-result はコピー（約7GB）
- 大容量データはシンボリックリンクで参照

| パス | 方法 |
| --- | --- |
| `CASIA-B/`（43GB） | シンボリックリンク → `/home/ryu/OpenGait/CASIA-B` |
| `CASIA-B-png/`（12GB） | シンボリックリンク → `/home/ryu/OpenGait/CASIA-B-png` |
| `output/`（31GB） | シンボリックリンク → `/home/ryu/OpenGait/output` |
| `train-result/`（6.7GB） | コピー |
| コード・configs等 | コピー |

```bash
rsync -av --exclude='CASIA-B' --exclude='CASIA-B-png' --exclude='output' --exclude='GaitDatasetB-silh' /home/ryu/OpenGait/ /home/kera/OpenGait/
ln -s /home/ryu/OpenGait/CASIA-B /home/kera/OpenGait/CASIA-B
ln -s /home/ryu/OpenGait/CASIA-B-png /home/kera/OpenGait/CASIA-B-png
ln -s /home/ryu/OpenGait/output /home/kera/OpenGait/output
```
