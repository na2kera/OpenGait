# 0705進捗: DeepGaitV2単独特徴量による精度予測の分析

Notionページ「0705進捗」の内容を整理し、DeepGaitV2のみを特徴量とした場合に
精度予測性能が論文（Inception/DINO使用）より低下した原因を分析したメモ。

## 1. 実験の全体像

### 1.1 データ分割の2つの軸

CASIA-Bは124人の被験者からなり、`datasets/CASIA-B/CASIA-B.json` で
**TRAIN_SET 74人 / TEST_SET 50人** に固定分割されている。この分割は
サブセットが変わっても共通。

- **74人（TRAIN_SET）**: DeepGaitV2モデルの重みを学習するために使う人たち。
  サブセットごとに「どの歩行条件（nm/bg/cl）・どの視点角度のシーケンスを
  訓練データに含めるか」を変えることで、13種類の訓練データ構成
  （`default`, `nm2`, `bg2`, `cl2`, `nm1-bg1`, `nm1-cl1`, `nm1-bg1-cl1`,
  `nm2-bg2-cl2`, `nm6`, `000-180`, `000-090`, `090-180`, `bg1-cl1`）を作る。
- **50人（TEST_SET）**: 学習には使わず、各サブセットモデルの認識精度
  （`acc_nm` / `acc_bg` / `acc_cl` / `acc_all`）を測るためだけに使う、
  固定の標準評価プロトコル。

### 1.2 パイプライン

1. 13サブセットそれぞれについて、そのサブセット専用に学習した
   DeepGaitV2モデルで埋め込みを抽出（`bg1-cl1` は学習済みモデルが
   無く欠測のため12/13で実施）
2. 埋め込みから MSD / 1NN / kNN / FID / FID(train-test) を計算
3. 各モデルを50人テストセットで評価して得た正解精度と、上記の特徴量を
   1サブセット=1行としてまとめる（`metrics_dgv2.json`）
4. **Leave-One-Subset-Out Ridge回帰**: 12行で学習・残り1行で評価、を
   対象を入れ替えて繰り返し、精度予測の汎化性能を測る
5. **Leave-One-Subset-Pair-Out ロジスティック回帰**: サブセットペアの
   優劣（A_better / B_better / Tie, τ=0.05）を、評価対象ペアが絡む
   学習ペアを除外して予測

Leave-One-Outで残す「1」は、その回のモデル学習には一切使わず、
学習済みモデルへの入力（特徴量）と答え合わせ（実測精度）のためだけに
使われる。これにより、未知のサブセットに対して実際に認識評価をしなくても
精度を当てられるか、をリークなく検証できる。

## 2. 結果

| | DeepGaitV2-only（今回, 12サブセット） | 論文（Inception/DINO, 13サブセット） |
|---|---|---|
| Ridge Spearman (acc_all) | 0.5594 | 0.8352 |
| 優劣判定 Accuracy | 0.6667 | 0.7949 |
| 優劣判定 Macro-F1 | 0.6435 | 0.7296 |

DeepGaitV2のみを特徴量にすると、論文の設定より予測性能が明確に低下した。

## 3. 精度低下の原因分析

### 3.1 主因: サブセット間で特徴量の「物差し」が揃っていない

各サブセットの埋め込みは**そのサブセット自身の学習済みDeepGaitV2モデル**
から抽出しており、Inception/DINOのような全サブセット共通モデルではない。
実測値を見ると、FID(クラス間)は 145.08〜861.41、MSDは 4.03〜42.91 と
サブセット間で10倍近いばらつきがある。これは「データの内在的な難易度が
10倍違う」というより、**モデルごとに埋め込み空間の尺度そのものが異なる**
ことの表れである可能性が高い。

Leave-One-Subset-Out回帰は「他サブセットの(特徴量→精度)関係」を学習して
未知のサブセットに当てはめる手法のため、特徴量の尺度が学習データ間で
揃っていないと一貫した関係を学習できず、汎化性能（Spearman相関等）が
落ちる。実際、モデル内で閉じた相対値である `FID_train_test_DeepGaitV2`
が全targetで最重要特徴になっており、モデルをまたいだ絶対値比較が
効きにくいことと整合的。

### 3.2 副因: DeepGaitV2は判別的（タスク特化）な埋め込みで、独立変数として循環している

DeepGaitV2は個体識別精度を最大化するように学習された埋め込みであるため、
「その埋め込み空間でクラスが分離しやすいか」は「そのモデル自身の認識精度が
高いか」とほぼ同じことを表しやすい。加えて訓練の収束度合いのばらつきが
ノイズとして混入し、「データ自体の内在的な複雑さ」を測る客観的な指標としての
独立性が薄れる。

Inception/DINOは認識タスクと無関係に学習された汎用特徴のため、認識モデルの
学習結果に左右されない、データそのものの性質を測れる点で予測変数として
安定している。

### 3.3 副因: サンプル数が少ない

12サブセット（Leave-One-Outで学習11点/fold）と少なく、上記の尺度不整合の
影響を平均化して打ち消すだけの標本数が不足している。

## 4. 今後の対応候補

- 各サブセット内で特徴量をz-score正規化してから回帰にかける
  （サブセット内の相対的な位置関係のみを利用する）
- 全サブセット共通の単一DeepGaitV2モデルで埋め込みを取り直し、
  Inception/DINOと同条件で比較する
- `bg1-cl1` の学習を完了させ、13/13サブセットで論文と同条件の比較を行う
  （優先度: 高）
